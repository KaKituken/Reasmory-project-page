# Reasmory — Project Page

Project page for **Reasmory: 3D Reconstruction as Explicit Memory for VLMs Spatial Reasoning** (BMVC 2026).

- [Paper](https://arxiv.org/pdf/2606.00963)
- [arXiv](https://arxiv.org/abs/2606.00963)
- [Code](https://github.com/KaKituken/Reasmory)

Static site (plain HTML/CSS/JS + three.js from CDN). The interactive point-cloud viewer loads a Pi3
reconstruction of VSI-Bench scene `scene0593_00` from `point_cloud/`.

Serve locally with any static server, e.g.:

```bash
python3 -m http.server 8000
```
